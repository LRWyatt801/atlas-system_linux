# Atlas System Linux

A repository containing projects for learning about the Linux system 

## Overview

This repository serves as a collection of educational projects aimed at deepening understanding of the Linux operating system and its kernel. It encompasses various topics, including system calls, multithreading, networking, and more.

## Repository Structure

The repository is organized into several directories, each focusing on a specific aspect of Linux systems:

- `0x08_CPython`: Projects related to CPython internals.
- `getline`: Implementations and experiments with the `getline` function.
- `libasm`: Assembly language exercises and examples.
- `ls`: Recreating the `ls` command to understand directory listings.
- `multithreading`: Examples demonstrating multithreading concepts.
- `nm_objdump`: Exploring binary analysis tools like `nm` and `objdump`.
- `proc_filesystem`: Investigations into the `/proc` filesystem.
- `readelf`: Working with the `readelf` utility for ELF files.
- `signals`: Handling and understanding Unix signals.
- `sockets`: Socket programming examples.
- `strace`: Using `strace` to trace system calls.
- `test_code`: Miscellaneous test code snippets.

## Getting Started

To explore the projects:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/LRWyatt801/atlas-system_linux.git
   ```


2. **Navigate to a project directory**:

   ```bash
   cd atlas-system_linux/<project_directory>
   ```


3. **Compile the code** (if applicable):

   ```bash
   make
   ```


4. **Run the executable**:

   ```bash
   ./<executable_name>
   ```


*Note*: Ensure you have the necessary permissions and dependencies installed for each project.
